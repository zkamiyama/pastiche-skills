# Pastiche Evidence Workbench

## Launch

```bash
python3 scripts/serve.py --out /private/profile
```

`character_graph.sqlite3` のある出力先を指定する。起動時に表示されるセッショントークン付きローカルURLを使う。トークンやprivateな原文をWeb公開しない。GUI閲覧のためにモデルサーバーへの通信を行わない。エディタを public bind に変更しない。

## Human review

左の検証キューまたは中央の線を選び、右の原文根拠を読む。主語・対象・作品版・提示時点を確認する。口調は話し相手と感情を、価値観は具体的な選択を、人物関係は方向を区別する。発話・推測・事実を同一視しない。

- **確認済み判定**: 任意の操作。出典ハッシュの一致を確認したうえで人間の判断として記録する。自動採用は未確認のまま使えるため、全件の確認は不要。
- **使用停止**: `revoke` により該当主張を出力から除外。`reject` は誤りの指摘、`defer` は保留。元の根拠と履歴は残し、再度確認済みにすれば復帰する。
- **訂正**: 元のモデル出力を保持し、人間の訂正を別バージョンとして保存。その場で `human_approved` に反映し、再承認を必要としない。
- **却下/保留**: 理由を残す。再解析で上書きしない。
- **人物統合**: 同一canon内で人間が判断。元の主張を破壊しない。履歴から解除できる。
- **手動追加**: 登録済み根拠IDが必要。根拠なしの設定を観測事実として登録しない。

時点スライダーは「その提示位置までに観測された情報」。期間不明は永続を意味せず、回想中の実時間と提示順は別。出典が変わった古い主張はstaleとなり、再確認なしでwriteへ渡さない。

物語構造タブは作品の階層・出来事・原文根拠を閲覧する。これは自由な物語グラフ編集や全因果の人間承認を行う画面ではない。

## Export

一つの作品版を選んで「執筆用に出力」。`writer_context.json` と `character_bible.md` に、出典が現行の自動採用・人間修正済み主張を状態ラベル付きで出す。構造パターンは別枠の `model_supported` 仮説として扱う。

エージェントが未確認の全件を `human_approved` にしてはならない。`auto_accepted` は本人確認済みでも確定事実でもない。合成テストの承認と実データの検証を混同しない。

## Troubleshooting

HTTP 409 は別タブの変更か原文変更を示す。再読込し、根拠を再確認してから再操作する。古いrevisionでの強制上書きはしない。原文のパスが見つからなければ、元のファイル配置または再解析を確認する。

データベースは一人用ローカル作業向け。multi-user/public-hostingの認証基盤ではない。バックアップはprivate出力ディレクトリ全体で保持する。

## 世界観タブ

「世界観」タブでは場所・組織・国家・文化・時代・資源・技術体系を型付きノードとして表示する。人物→組織の所属や世界設定→出来事の参照をたどれる。右側で法則の条件・例外・modality・肯否・作中の時期を検査／訂正する。使用停止などの既定方針は人物情報と同じ。

同一性の統合は型と作品版が一致する場合だけ可能。異なる型や原作／アニメの設定を強制統合しない。矛盾候補は「同一の関係について肯否が異なる」という限定的検査であり、万能な設定矛盾検出ではない。

「執筆の世界」で新世界／選択版の世界を指定し「執筆用に出力」する。`world_context.json` と `world_bible.md` に現行の利用可能な主張が保存される。出力後に訂正・撤回した場合は再出力する。
